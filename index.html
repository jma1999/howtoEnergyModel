Energy Modeling Tutorial

How to Build a Basic Energy Model in eQUEST

This tutorial walks through the process of creating a simplified building energy model, assigning envelope and system inputs, running a simulation, and reviewing energy results.

Learning Objectives

  • Start a new eQUEST project.
  • Select a project location and weather file.
  • Define basic building geometry.
  • Enter envelope, lighting, equipment, and occupancy assumptions.
  • Select a basic HVAC system.
  • Run the simulation and review results.

Step 01

Start a New Project

Open eQUEST and begin a new project using the schematic design wizard. Enter the project name, building type, and basic project information.

Why this matters

The project setup establishes the foundation for the model and determines the starting assumptions used in later wizard screens.

Step 02

Select the Location and Weather File

Choose the project location and assign the appropriate weather file. The weather file allows eQUEST to estimate heating and cooling loads using local climate data.

Common mistake

Do not skip or guess the weather file. The climate file can strongly affect annual energy use, peak loads, and system performance.

Step 03

Run the Simulation and Review Results

After completing the input screens, save the project and run the simulation. Review annual energy use, monthly consumption, peak demand, and end-use breakdowns.

What to check

  • Does the simulation run without fatal errors?
  • Are heating and cooling results reasonable?
  • Do lighting, equipment, and HVAC end uses look realistic?
  • Are there unusual spikes in monthly energy use?

Final Checklist

Before submitting your model, confirm the following:

  • The correct project location and weather file are selected.
  • The building area, number of floors, and orientation are accurate.
  • Envelope assumptions are documented.
  • Occupancy, lighting, and equipment loads are reasonable.
  • The HVAC system type matches the tutorial or assignment requirements.
  • The simulation runs successfully.
  • Annual energy results and end-use summaries are recorded.
