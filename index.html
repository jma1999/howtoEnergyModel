eQUEST Energy Modeling Tutorial

Create a basic building energy model and review simulation results.

Learning Objectives

By the end of this tutorial, you will be able to set up a basic eQUEST model, assign building systems, run a simulation, and interpret key energy results.

Software Needed

  • eQUEST installed on your computer
  • Project description or assignment prompt
  • Building dimensions, schedules, and basic HVAC information
  • Weather/location information for the project site

Exercise Overview

In this exercise, you will create a simplified energy model for a building. The model will include location data, building geometry, envelope properties, internal loads, schedules, HVAC systems, and simulation results.

Step 1: Start a New Project

Open eQUEST and create a new project using the schematic design wizard. Enter the project name, building type, and basic project information.

Step 2: Set the Location and Weather File

Choose the project location and assign the appropriate weather file. This allows eQUEST to simulate the building using local climate conditions.

Step 3: Define Building Geometry

Enter the building footprint, number of floors, floor-to-floor height, zoning layout, and orientation. Keep the geometry simple for this exercise.

Step 4: Add Envelope Information

Define wall, roof, window, and floor assemblies. Include insulation values, glazing type, window-to-wall ratio, and shading assumptions where required.

Step 5: Define Occupancy, Lighting, and Equipment Loads

Enter internal load assumptions such as people density, lighting power density, plug loads, and operating schedules.

Step 6: Select HVAC Systems

Choose an HVAC system type appropriate for the building. For a basic tutorial, use a simple packaged rooftop unit, VAV system, or system type assigned by your instructor.

Step 7: Run the Simulation

Save your project, check for input errors, and run the simulation. If the model does not run, review the error messages and correct missing or conflicting inputs.

Step 8: Review Results

Review annual energy use, monthly energy use, peak demand, and end-use breakdowns. Compare the results with expected building behavior.

Common Errors

  • Missing or incorrect weather file
  • Unrealistic building geometry
  • Schedules that are always on or always off by mistake
  • Incorrect HVAC system selection
  • Simulation errors caused by incomplete inputs

Submission Checklist

  • Project file saved successfully
  • Simulation runs without fatal errors
  • Annual energy results are recorded
  • End-use breakdown is reviewed
  • Screenshots of key input screens are included
  • Short explanation of modeling assumptions is written
